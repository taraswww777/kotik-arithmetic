# 07. Группы и соревнования (архитектурный задел)

## Модель данных:
- [ ] Создание таблиц:
  - `User` — пользователи системы
  - `Group` — объединения пользователей (класс, семья)
  - `GroupMember` — связь User ↔ Group

## Соревнования:
- [ ] Создание таблиц:
  - `Competition` — соревнования с заданными правилами сравнения
  - `CompetitionEntry` — записи участников соревнований

## API:
- [ ] CRUD для групп (создание, чтение, обновление, удаление)
- [ ] CRUD для соревнований
- [ ] Регистрация участника в соревновании

## Примечание:
- На первом релизе группы и соревнования могут отсутствовать в UI
- Схема данных и API должны допускать их добавление без переработки ядра
