# 03-02. Генерация сетки кроссворда (grid placement)

## Подзадачи:
- [ ] Создать пакет `/packages/shared/src/crossword-generator/grid/` с функциями:
  - `generateGrid(examples: Example[]): Grid`
  - `type Grid = { cells: Cell[], examples: Record<string, CrosswordExample> }`

### Расположение примеров в сетке:
- [ ] Определить координаты для каждого примера:
  ```ts
  type CrosswordExample = {
    id: string;
    expression: string;           // "2 + 3" или "5 × 7"
    answer: number;               // "5" или "35"
    direction: 'horizontal' | 'vertical';
    position: GridPosition;
  };

  type GridPosition = {
    row: number;
    col: number;
    width: number;                // количество символов (число + знак + число)
    height: number;               // для вертикальных примеров
  };
  ```

### Определение направлений:
- [ ] Горизонтальные примеры (по умолчанию):
  - Примеры сложения/вычитания (2+3, 5-1=4) — 1 строка
  - Примеры умножения (7×8=56) — 2 строки (число + знак + число)
  - Деление (9÷3=3) — 2 строки (делимое ÷ делитель = частное)

### Генерация сетки:
- [ ] Создать двумерный массив клеток `grid[row][col]`
- [ ] Поместить примеры без конфликтов (пересечений в одной клетке)
- [ ] Определить пустые клетки как те, которые должны заполнить пользователь

## Типы клеток:
- [ ] Заполненная числом — подсказка из примера
- [ ] Знак действия — оператор (+, -, ×, ÷)
- [ ] Равенство (=) — разделитель левых/правых частей
- [ ] Пустая клетка — для ввода пользователем

## Валидация сетки:
- [ ] Проверка отсутствия пересечений символов в одной клетке
- [ ] Проверка достаточности подсказок (минимум 1 число из примера)

## Критерии готовности:
- Сетка корректно генерируется для всех комбинаций примеров
- Пустые клетки определены правильно
