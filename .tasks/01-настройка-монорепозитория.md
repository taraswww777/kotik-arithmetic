# 01. Настройка монорепозитория

## Подзадачи:
- [ ] Выбрать инструмент управления (pnpm workspaces, npm workspaces, Turborepo или Nx) — **npm workspaces**
- [ ] Создать структуру репозитория:
  - `/apps/client` — фронтенд PWA
  - `/apps/server` — бэкенд Node.js
  - `/packages/shared` — общие типы и константы (кроссворды, модели данных)
  - `/packages/config` — ESLint, TypeScript, Prettier
- [ ] Настроить workspace (npm workspaces)
- [ ] Создать корневой `package.json` с метаданными проекта
- [ ] Настроить скрипты для сборки фронтенда и бэкенда
- [ ] Настроить тестовую среду (vitest + jest):
  - **В client**: `vitest` + React Testing Library, конфиг `vitest.config.ts`
  - **В server**: `jest` или `vitest` для Unit-тестирования API, `jest.setup.ts`
  - **В shared**: унитарные тесты для типов и констант
  - Настроить coverage отчётность в корне workspace
- [ ] Интегрировать CI (GitHub Actions):
  - Запускать тесты перед деплоем
  - Лимит покрытия кода для push'а ветки

## Критерии готовности:
- Команда `npm install` успешно завершается
- В корне видны ссылки на workspace-пакеты
- Можно импортировать общие типы из `/packages/shared` во фронтенде и бэкенде
- Все тесты проходят: `vitest run && jest`
- Code coverage соответствует требованиям (≥20% для unit-тестов)
