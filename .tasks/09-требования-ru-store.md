# 09. Требования к модерации RuStore

## Возрастная маркировка:
- [ ] Подготовить описание приложения (обучающая игра без спорного контента)
- [ ] Указать возрастную категорию в соответствии с содержанием

## Политика конфиденциальности:
- [ ] Написать политику на русском языке (если приложение собирает email)
- [ ] Разместить ссылку в карточке RuStore
- [ ] Реализовать внутри приложения доступ к политике
- [ ] Предусмотреть возможность удаления аккаунта

## Качество приложения:
- [ ] Тестирование на нескольких устройствах/версиях Android
- [ ] Проверка на ошибки вёрстки
- [ ] Проверка стабильности запуска
- [ ] Функциональное тестирование всех заявленных функций

## Карточка приложения:
- [ ] Название (соответствие функционалу)
- [ ] Иконка (совпадение в карточке и установленном приложении)
- [ ] Минимум 3 скриншота на тип устройства
- [ ] Описание, отражающее реальный интерфейс
