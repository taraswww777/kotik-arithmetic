# 00-01. Локальное тестирование перед деплоем (E2E)

## 🎯 Цель задания:
Провести локальное тестирование всех компонентов проекта до деплоя на VPS.

## 📋 Подзадачи:

### 1. Настройка окружения для тестирования:
- [ ] Установить все зависимости (`npm install` в корне workspace)
- [ ] Проверить, что `apps/client` запускается локально (`npm run dev --workspace=apps/client`)
- [ ] Проверить, что `apps/server` запускается локально (`npm run dev --workspace=apps/server`)
- [ ] Создать тестовую базу PostgreSQL (локальная Docker Compose или SQLite для разработки)

### 2. Тестирование фронтенда:
- [ ] Открыть PWA в браузере и проверить:
  - Отображение всех экранов (настройки, кроссворд, результаты)
  - Адаптивность под мобильные устройства
  - Корректность отображения символов умножения/деления (×/*, ÷/:)
- [ ] Проверить офлайн режим:
  - Отключить интернет
  - Проверить запуск приложения
  - Проверить работу уже загруженного контента

### 3. Тестирование бэкенда:
- [ ] Проверить работу аутентификации (регистрация/вход по email)
- [ ] Проверить сохранение результатов в PostgreSQL
- [ ] Проверить API для получения статистики

### 4. Интеграционное тестирование:
- [ ] Полный цикл: регистрация → генерация кроссворда → решение → сохранение результата
- [ ] Проверка работы таймера и завершения игры
- [ ] Проверка корректности отображения результатов

## 📝 Критерии готовности:
- ✅ Все компоненты запускаются локально без ошибок
- ✅ Фронтенд работает как офлайн PWA
- ✅ Бэкенд корректно обрабатывает запросы и сохраняет данные в БД
- ✅ Полный цикл работы игры протестирован
