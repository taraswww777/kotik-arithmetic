# 02-03. DevOps: инфраструктура и деплой (VPS + HTTPS)

## Подзадачи:
- [ ] Выбрать российского VPS (например, `rdp-onedash.ru`)
- [ ] Настроить домен и HTTPS через Let's Encrypt (certbot или аналог):
  - Автоматическое продление сертификатов (`certbot renew --dry-run`)
  - Настройка автообновления и мониторинга истечения сертификата
- [ ] Развернуть PostgreSQL БД:
  - Создать базу данных для приложения
  - Настроить резервное копирование (cron + `pg_dump`)
- [ ] Развернуть NestJS сервер на VPS:
  - Запуск через PM2 (`pm2 start dist/main.js`)
  - Настройка автозапуска при рестарте сервера (`systemd` или PM2)
- [ ] Настроить мониторинг логов (PM2 logs + системный лог):
  ```bash
  pm2 logs app-name --lines 100
  ```

## Безопасность:
- [ ] Настроить брандмауэр (firewalld/ufw) — разрешить только HTTPS и SSH
- [ ] Настроить регулярные резервные копии БД (ежедневно, с хранением 7 дней)

## Мониторинг:
- [ ] Подготовить место для future Prometheus + Grafana (архитектурный задел)
- [ ] Настроить alerting при падении сервиса (через PM2 monitoring)

## Критерии готовности:
- Сервер запущен и доступен по HTTPS
- Бэкапы выполняются автоматически
- Логи собираются и доступны через `pm2 logs`
