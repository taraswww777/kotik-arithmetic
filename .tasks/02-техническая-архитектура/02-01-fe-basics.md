# 02-01. Фронтенд: базовая настройка (Vite + PWA)

## Подзадачи:
- [ ] Настроить Vite проект с React + TypeScript
- [ ] Добавить `vite-plugin-pwa` для офлайн-режима
- [ ] Настроить Service Worker (кэширование оболочки и контента кроссвордов)
- [ ] Реализовать адаптивную верстку (мобильные экраны + десктоп)
- [ ] Установить Emotion для стилей:
  - `@emotion/react`, `@emotion/styled` в зависимости
  - Настроить `createCache` + `hydrateRoot` для PWA офлайн
  - Подготовить CSS-in-JS компоненты (кнопки, поля ввода, сетка кроссворда)

## Стилистика:
- [ ] Контрастный интерфейс для детей 5–9 лет
- [ ] Крупные интерактивные элементы
- [ ] Минимум текста, визуальные подсказки

## Критерии готовности:
- Игра работает в браузере и как офлайн PWA на Android
- Стилизация через Emotion завершена для всех компонентов UI
