# System Requirements

## Frontend (Client):
```bash
Node.js >= 18.0.0
npm >= 9.0.0
```

## Backend (Server):
```bash
Node.js >= 18.0.0
PostgreSQL >= 15
Prisma ORM
```

## Docker:
```bash
Docker >= 24.0.0
Docker Compose >= 2.20.0
```

## VPS Minimum Specs (Production):
- CPU: 2 vCPU
- RAM: 2GB
- Storage: 20GB SSD
- Bandwidth: 100Mbps

## Recommended Specs (Production):
- CPU: 4 vCPU
- RAM: 8GB
- Storage: 50GB NVMe SSD
- Bandwidth: 1Gbps
