# Задача 05: Статистика и прогресс — ВЫПОЛНЕНО ✅

## Реализовано

### Локальное хранение (IndexedDB) — Этап 1

#### ✅ Схема хранилища для записей о кроссвордах
```ts
{ 
  id?: string,                      // auto-generated
  crosswordId: string,              // уникальный ID кроссворда
  timeSpent: number,                // время в секундах
  mistakes: number,                 // количество ошибок
  operations: string[],             // использованные операции
  difficulty: 'basic' | 'advanced', 
  solvedCount: number,              // решённых примеров
  totalSolved: number,              // всего примеров
  completedAt: number,              // timestamp завершения
  userId?: string                   // опциональный userId
}
```

#### ✅ Реализация persistence через перезапуск приложения
- Используется нативный IndexedDB API
- Хранилище `kotik-arithmetic-db.gameResults` с индексом по `completedAt`, `difficulty`, `userId`
- Фоллбэк на localStorage при ошибках
- Автоочистка старого JSON хранилища

**Файл:** [`apps/client/src/services/storage.ts`](<../apps/client/src/services/storage.ts>)

#### ✅ Сохранение статистики при завершении каждого кроссворда
- Автоматическое сохранение в `handleGameEnd()` в компоненте `CrosswordGame`
- Генерация уникального `crosswordId` на основе timestamp
- Вызов через кнопку "Сохранить в историю" в ResultsScreen

**Интеграция:**
- [`apps/client/src/components/CrosswordGame.tsx`](<../apps/client/src/components/CrosswordGame.tsx>)
- [`apps/client/src/App.tsx`](<../apps/client/src/App.tsx>)

### Синхронизация (PostgreSQL) — Этап 2

#### ✅ Таблица `game_results` с привязкой к `user_id`
```prisma
model GameResult {
  id          String   @id @default(uuid())
  userId      String
  crosswordId String
  timeSpent   Int
  mistakes    Int
  operations  String[]
  difficulty  String
  completedAt DateTime
  
  user        User      @relation(fields: [userId], references: [id])
  
  @@index([userId])
  @@index([crosswordId])
}
```

**Файл:** [`apps/server/prisma/schema.prisma`](<../apps/server/prisma/schema.prisma>)

#### ✅ API для выгрузки статистики на сервер
**Эндпоинты NestJS:**

| Метод | URL | Описание |
|-------|-----|----------|
| `POST` | `/stats/game-result` | Сохранение результата игры |
| `GET` | `/stats/user/:userId` | История результатов пользователя |
| `GET` | `/stats/top-players` | Топ игроков |
| `GET` | `/stats/difficulty-distribution` | Распределение по сложности |

**Controller:** [`apps/server/src/stats/stats.controller.ts`](<../apps/server/src/stats/stats.controller.ts>)

**Service:** [`apps/server/src/stats/stats.service.ts`](<../apps/server/src/stats/stats.service.ts>)

#### ✅ API для чтения агрегированной статистики с сервера
```
GET /stats?difficulty=basic
GET /stats/advanced
```

**Ответ:**
```json
{
  "totalGames": 5,
  "solvedCount": 15,
  "averageTimeSpent": 280.5,
  "averageMistakes": 3.2,
  "difficultyCounts: {
    "basic": 4,
    "advanced": 1
  }
}
```
