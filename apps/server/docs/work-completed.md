# Выполненная работа: Аутентификация и Ролевая модель

## ✅ Реализовано:

### 1. База данных (Prisma schema):
- Добавлены поля в модель `User`:
  - `userId` — внутренний ID для интеграции с внешними системами
  - `externalId` — внешний идентификатор (VK ID, MAX ID, ЕСИА ID)
  - `role` — роль: `USER_ROLE_CHILD` (ребёнок), `USER_ROLE_PARENT` (родитель)
  - `organizerId` — ID организатора группы
- Добавлены enum:
  - `UserRole` — типы ролей пользователей
  - `MemberRole` — роли участников группы

### 2. JWT Authentication:
- ✅ Модуль конфигурации JWT (`src/config/jwt-config.module.ts`)
- ✅ Стратегия Passport для JWT токенов (`src/config/jwt/jwt.strategy.ts`)
- ✅ Утилиты для создания/проверки токенов (`src/config/jwt/utils/tokens.ts`)
- ✅ Утилиты для хэширования паролей (`src/config/jwt/utils/passwords.ts`)

### 3. Ролевая модель:
- ✅ Реализация ролей `ребёнок` и `родитель` в Auth Service
- ✅ UI: скрытие/показ функций в зависимости от роли (через `/auth/role`)
- ✅ Проектирование сущности `организатор группы` в модели Group

### 4. API Endpoints:
- `POST /auth/register` — Регистрация пользователя
- `POST /auth/login` — Вход и получение JWT токена
- `GET /auth/role` — Проверка роли пользователя (для UI)
- `POST /auth/validate` — Валидация токена
- `POST /auth/refresh` — Обновление токена

### 5. Архитектурный задел для OAuth провайдеров:
- ✅ Единый внутренний `userId`, к которому привязываются внешние идентификаторы
- ✅ Готовность для интеграции `nestjs-vkid` или `passport-vk-id`
- ✅ Модуль аутентификации с абстракцией провайдера
