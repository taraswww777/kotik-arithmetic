# 🐱 Маскот-Котик

Краткая документация по работе с маскотом в проекте "Котик в мире арифметики".

## Структура

```
apps/client/src/components/mascot/
├── Mascot.tsx              # Компонент отображения котика
├── hooks/
│   └── useMascot.ts        # Хук для реактивной логики
└── index.ts                # Экспорт компонентов

packages/shared/src/config/
└── mascot.ts               # Конфигурация реплик (отдельно от кода!)
```

## Реализованное ✅

### Внешний вид
- [x] Котик в учительской шляпе 🐱🎓 (атрибут)
- [x] Анимации: сидит, лежит, стоит на полянке (автоматически меняются каждые 15 сек)
- [x] Постоянное присутствие в углу экрана (фиксированное позиционирование)
- [x] Кнопка скрытия/показа (встроенная в UI)

### Поведение и реплики
- [x] Реплика при правильном решении — похвала (зелёный пузырь)
- [x] Подсказки (текстовые, жёлтые пузыри)
- [x] Указание на ошибку с объяснением (красный пузырь)
- [x] Тексты реплик хранятся в конфигурационных файлах (`packages/shared/src/config/mascot.ts`)

### Подготовка к голосовому сопровождению
- [x] Разделение логики и контент (реплики в внешних файлах)
- [x] Возможность добавления аудио без переписывания логики (готовый интерфейс)

## Использование

### В компоненте игры:

```tsx
import { useMascot } from '@kotik-arithmetic/config/mascot';

const MyGameComponent = () => {
  const { 
    showSuccessMessage, 
    showError, 
    showHint,
    handleFocus 
  } = useMascot();

  return (
    <div>
      {/* При правильном ответе */}
      <button onClick={() => showSuccessMessage()}>
        Правильно!
      </button>

      {/* При ошибке */}
      <button onClick={() => showError()}>
        Попробуй ещё
      </button>

      {/* Автоматическое скрытие при фокусе */}
      <input onFocus={(e) => handleFocus(e.target)} />
    </div>
  );
};
```

### Добавление новых реплик:

Откройте `packages/shared/src/config/mascot.ts` и добавьте свои сообщения:

```typescript
export const mascotMessages: MascotMessage[] = [
  // ... существующие сообщения
  
  // Новая похвала
  { id: 'good_6', text: 'Ты настоящий волшебник в арифметике!', type: 'success' },
  
  // Новая подсказка
  { 
    id: 'hint_6', 
    text: 'Подсказка: попробуй разложить число на множители', 
    type: 'hint',
    trigger: 'stuck'
  },
];
```

## Конфигурация маскота

В `packages/shared/src/crossword-generator/types.ts`:

```typescript
export interface MascotConfig {
  position: 'sit' | 'lie' | 'stand';          // Состояние котика
  positionChangeInterval: number;              // Частота смены позы (мс)
  autoHideOnFocus: boolean;                    // Авто-скрытие при фокусе
  showWelcomeMessage: boolean;                 // Приветственное сообщение
}
```

## Типы сообщений

### success (похвала 🌟)
- Отображаются в зелёном пузыре
- При правильных ответах
- Примеры: "Молодец!", "Отлично!", "Правильно!"

### hint (подсказка 💡)  
- Отображаются в жёлтом пузыре
- Когда пользователь застрял
- Примеры: "Вспомни таблицу умножения..."

### error (ошибка ❌)
- Отображаются в красном пузыре
- При неверных ответах
- Примеры: "Проверь ещё раз!", "Не переживай!"

## Анимации

Котик имеет три состояния:
- **sit** (сидит) — по умолчанию, в углу экрана
- **lie** (лежит) — более расслабленная поза
- **stand** (стоит) — активная поза

Смена позы происходит автоматически каждые 15 секунд.

## Стилизация

Все стили определены через `styled-components`:
- Можно изменить цвета пузырей в `Mascot.tsx`
- Размер котика зависит от позы
- Позиционирование фиксировано, не перекрывает игровое поле

## Тестирование

1. Откройте приложение в браузере
2. Котик должен появиться в правом нижнем углу
3. Каждые 15 секунд поза котика меняется
4. При клике на котика можно скрыть/показать
5. Пузыри появляются только при взаимодействии (через хук)
