# Конфигурационные файлы

## Общие настройки конфигурации

В папке `src/config` находятся все константы и типы, используемые по всему приложению:

- **difficulty.ts** — уровни сложности (elementary, primary, lowerSecondary, upperSecondary)
- **operations.ts** — типы операций (+, -, *, /) и наборы
- **settings.ts** — настройки пользователя
- **mascot.ts** ← **новые!** — реплики и настройки маскота

## Маскот-конфигурация (mascot.ts)

### Структура сообщений

Все тексты реплик хранятся в отдельном файле `mascot.ts`:

```typescript
export interface MascotMessage {
  id: string;          // уникальный ID для отслеживания
  text: string;        // текст сообщения
  type: 'success' | 'hint' | 'error'; // тип реакции
}
```

### Типы сообщений

#### success — похвала 🌟
Показываются при правильных ответах (зелёный пузырь):
- "Молодец! Правильно!"
- "Отлично! Ты супер!"
- "Правильно! Продолжай так!"

#### hint — подсказка 💡
Показываются когда пользователь застрял (жёлтый пузырь):
- "Попробуй вспомнить таблицу умножения..."
- "Подсказка: результат больше первого числа"

#### error — ошибка ❌
Показываются при неправильных ответах (красный пузырь):
- "Ой-ой! Что-то не так..."
- "Проверь ещё раз вычисления"

### Добавление новых сообщений

Просто добавьте в массив `mascotMessages`:

```typescript
// Похвала
{ id: 'good_6', text: 'Ты настоящий волшебник в арифметике!', type: 'success' },

// Подсказка  
{ 
  id: 'hint_6', 
  text: 'Подсказка: попробуй разложить число на множители', 
  type: 'hint',
  trigger: 'stuck'
},

// Ошибка
{ id: 'error_5', text: 'Не расстраивайся, у тебя получится!', type: 'error' },
```

### Экспорт модулей

Из `packages/shared/src/config/index.ts` экспортируются все типы и данные:

```typescript
export * from './difficulty';     // уровни сложности
export * from './operations';     // операции
export * from './settings';       // настройки
export * from './mascot';         // реплики маскота ← новые!
```

## Использование в приложении

### Импорт

```typescript
import { mascotMessages } from '@kotik-arithmetic/config/mascot';
import { difficultyLevels } from '@kotik-arithmetic/config/difficulty';
```

### Валидация

Все конфиги можно валидировать через Zod или другие схемы. Создайте `src/validation/` для этого.
